Honesty notes

  • Testnet demo. Never say "live" or "in production."
  • 5,000 scale: the code has batching (100 per batch, up to 10 in parallel), per-recipient isolation, and idempotent retries. There's no dated test at 2,000 or 5,000. A long run may hit the Edge Function wall-clock limit; it's built to resume via retry. Don't quote speed or throughput.
  • Offline: code exists in src/services/offline/, but package.json has no Bluetooth library and the docs disagree on its status. Confirm on device.
  • SMS invites and merchant cash-out are simulated.
  • All names, numbers, and stores are placeholders. No partners are implied.
