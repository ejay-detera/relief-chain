# Relief Chain

Relief Chain is an Expo React Native application.

## Prerequisites

Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/)
- npm (comes with Node.js)
- [Expo Go](https://expo.dev/client) app on your iOS or Android device (for physical device testing), or setup iOS Simulator/Android Emulator on your local machine.

## Setup Instructions

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone <repository-url>
   cd relief-chain
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm start
   ```
   or
   ```bash
   npx expo start
   ```

4. **Run the app**:
   - Press `i` in the terminal to open in an iOS simulator.
   - Press `a` in the terminal to open in an Android emulator.
   - Press `w` in the terminal to open in a web browser.
   - Scan the QR code shown in the terminal with the Expo Go app on your physical device.

## Project Structure

- `src/app`: Contains the file-based routing screens.
- `src/components`: Contains reusable UI components.
- `assets`: Contains static assets like images and fonts.

## Additional Commands

- `npm run ios`: Start the app directly in the iOS simulator.
- `npm run android`: Start the app directly in the Android emulator.
- `npm run web`: Start the app directly in the browser.
- `npm run lint`: Run the linter to check for code issues.
